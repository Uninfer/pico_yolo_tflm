# 模型说明

## 当前嵌入模型

模型以 TFLite FlatBuffer 字节数组形式存放在 `src/inference/models/fire/Fire_int8_weight.cc`。相邻头文件声明的类别如下：

| 类别 ID | 标签 |
| --- | --- |
| 0 | fire（火焰） |
| 1 | smoke（烟雾） |

当前应用将 240 × 320 RGB565 摄像头帧缩放至 192 × 192，转换为 RGB 通道后写入 int8 输入张量。后处理将输出解释为检测框坐标和类别分数，并使用 0.40 置信度阈值及 0.30 IoU 阈值。

这些信息根据当前源码整理。替换或发布模型前，须用实际嵌入的模型核实张量形状、量化参数、坐标尺度、颜色通道顺序和类别顺序。

## 来源和再分发

仓库没有记录 `Fire_int8_weight.cc` 的模型卡、训练数据引用、原始模型地址、作者或模型许可证，因此目前无法确认再分发权利。该模型权重不属于项目 Apache-2.0 许可范围。确认权利人和适用条款前，不要把模型声明为 Apache-2.0，也不要将它放入对外发布的固件。

`src/inference/assets/video_frames.h` 中的 RGB565 数据也需要相同的来源核查。
