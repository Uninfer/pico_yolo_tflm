# Pico YOLO 开发计划

仅跟踪本项目的摄像头预览、YOLO 推理和检测显示。

## 已完成

- 固定目标为 Waveshare RP2350-Touch-LCD-2-C，使用 OV5640 摄像头和 ST7789 屏幕。
- 采用单帧所有权交接，预览可与 TFLM 预处理和推理并行。
- 启用 CMSIS-NN、固定尺寸预处理和批量检测框绘制。
- 默认系统时钟设为参考工程使用的 300 MHz，并保留 150 MHz 配置选项。

## 后续

- 记录不同系统时钟下的预处理、TFLM Invoke、后处理耗时和端到端检测帧率。
- 用保存的图像核实模型输入颜色顺序、量化参数、类别和检测框坐标。
- 确认模型权重与示例帧的来源和再分发许可，之后再制作对外发布固件。
- 发布时记录固件构建环境、模型标识和 UF2 校验和。
